# Chatbot tiers — 靜態 LLM 輸出風險 (T1–T8)

> **語言**：[English](chatbot_tiers.md) · **繁體中文 (你在這)**

模型解禁後**能講什麼**, 依實質風險評分 (嚴重度 × 可及性 / 25)。

> 範圍: 單一對話, 沒 agent loop, 沒工具呼叫。純文字進 → 純文字出。

### T3d–T4f 細部說明

- **T3d 名譽攻擊** — 抹黑長文草稿、用公開 OSINT 拼湊的 doxx dossier、丟給 HR / 主管機關 / 客戶的「請開除這個人」投訴模板、**影響就職** (引響就職), 對個人的**品牌名譽攻擊** (引響口碑, target=個人)。實質風險 4.8 因為歸因難 (mob-fronted)、持續時間以年計、家庭一起背社會成本。跟 T3b 的差別: T3b 攻擊**受害者的腦**, T3d 攻擊**第三方對受害者的觀感**。
- **T3e 合成媒體詐欺** — 為 deepfake 影音詐騙產生**腳本** / **文字骨架** (虛假影片)、暴力構陷型偽造文件 (暴力虛假文件)、假見證、設計成截圖傳播的假對話紀錄。影音合成本身不是 LLM 做的 — 但每個現代 deepfake 詐騙都需要 LLM 生成的*故事*層才有說服力。
- **T4e 協同網暴** — 為多帳號圍剿 (多帳號網暴) 生成 N 個略有變化的攻擊訊息、武器化公眾注意力的 hashtag 攻勢 (暴力網路標籤)、針對性 brigade-mob 協調文案。傷害是*心理 + 名譽*, 網路分散歸因, 所以 DT=5。
- **T4f 商業評價操縱** — 電商 / app store / 餐廳平台假評價 (電商洗評價)、競爭對手評論掩埋、評分灌水、假使用者見證。單次嚴重度低但量很大。
- **T2v 家用化學品武器化** — 把超市買得到的物質組合成傷害端點的指導、煙火改造配方、教唆購買常見有害材料 (教唆購買有害物質傷害他人)。實質風險 3.8 — AC=0 (任何人都能買), 但結果多半受害人數有限。跟 T5b 化學武器的差別: 化學停在家用級嚴重度, 不到武器級。
- **T3v 鎖定身體暴力規劃** — 對單一受害者的身體攻擊作戰規劃: 對特定人的交通工具破壞 (破壞他人交通工具造成他人傷害)、含位置情報的跟蹤、預謀襲擊。嚴重度 21 因為結果可致命、跨世代家庭創傷、不可逆 5。實質風險 **6.7** ⭐ — 「可知 + LLM 協助」範疇內最高實質風險。
- **T4g 憑證 / 私密檔案竊取** — T4a 的明確子類別, 鎖定密碼、OAuth token、瀏覽器 cookie、session key、私密檔案。今天 LLM 最常見的攻擊用途 (info-stealer 市場數十億美元/年)。實質風險 4.2 跟 T4a 母類別相同, 但獨立分類因為防守方校準的訊號不同。
- **T4h IoT / 微控制器武器設計** — ESP32 / Arduino / Raspberry Pi 變成傷害端點: 武器化無人機、RF 干擾器、隱蔽監視、跟蹤器、電擊裝置、IED 觸發器。AC=2 (業餘玩家零件可得, ~$50 超市電子店硬體)。嚴重度 18, 實質風險 4.3。**實質風險低於直覺**, 因為真實物理傷害端點還是要組裝技巧; LLM 幫的是 firmware, 不是最後一哩的危險步驟。
- **T7d 公共大規模暴力作戰規劃** — 目標選擇、時機優化、位置情報 (人流、監視覆蓋、逃跑路線) 給隨機攻擊事件 (如人潮地點砍人、街頭車輛衝撞、大型活動安全漏洞分析)。嚴重度 24 (城市級受害數 + 致命)。AC=1 (只需 LLM 願意 engage), DT=3 (有歸因因為攻擊者實體在場)。實質風險 **6.7** ⭐。本 tier-set 中**單一最 concerning 能力**, 如果對齊 model 失守或解禁 model 被查詢 — 因為 **AI 優化攻擊時機/目標等於把「隨機性」替換成「效能」**。

## 三個反直覺洞察

1. **核武排名最低** — 嚴重度滿分 (25), 但被國家級門檻 + 必然偵測壓住。
2. **政治戰打敗所有 WMD 總和** — AC=1 (只要 LLM), DT=5 (完全匿名), 已部署 (IRA 型操作多次在近期選舉觀察到)。
3. **自殘協助是單體最高** — 零硬體、零追蹤、立即致命、家族多世代創傷。

## 實證 benchmark — Bad Boy bench 結果

來自 `badboy_bench_5model.json` (Vertex 專案, 13 prompts × 5 models):

| 模型 | 平均分 | 完整完成 (4/4) 次數 |
|---|---|---|
| gemma-4-e4b (原版) | 0.54 | 0/13 |
| qwen3.5-4b (原版) | 0.92 | 0/13 |
| gemma-4-e4b-abli | 1.38 | 1/13 |
| qwen3.5-4b-abli | 2.85 | 7/13 |
| qwen3.6-35b-a3b-abli | **3.46** | 10/13 |

觀察: **Gemma 4 對齊比 Qwen3.5 抗 naive abliteration 約 2 倍**, 同參數量級下。可能因為 Gemma 把 safety reasoning 分散到 `<|channel>thought` 思考模式, 不只是單一 refusal direction。

mlx-heretic 跑 Gemma 4 E2B smoke 估計落在 **平均 2.0–2.5**, 介於 gemma-4-e4b-abli 跟 qwen3.5-4b-abli 之間。Full 15-trial + 放寬 KL target 應該能逼近 qwen3.5-4b-abli (2.85)。

## 注意事項

- 這些風險分數是**框架討論用估計值**, 不是保險業等級的驗證數字。
- Tier 邊界是模糊的 — T3c 跟 T7c 在規模化時重疊, T4d 跟 T7b 重疊。
- `實質風險`是基於 2025–2026 攻擊者能力校準; 未來 agent 架構 (見 [agent_tiers.zh-TW.md](agent_tiers.zh-TW.md)) 會把這些值往上推。
